# iSilo Recovery - Windows Standalone

**Read your classic iSilo .pdb documents on modern Windows — free, no subscription needed.**

## Requirements
- Python 3.8+ (download from https://www.python.org/downloads/)
- tkinter (bundled with Python on Windows by default)

## How to Use
1. Double-click **iSilo Recovery.bat** (or run `python isilo_recovery.py`)
2. Click **Open .pdb file(s)** to add documents to your library
3. Click a document in the library list to read it
4. Use **+A / -A** to adjust font size
5. Use **Save as .txt** to export document text

## Supported Formats
- iSilo 3.x (type: iSil / creator: iSil)
- iSilo 4.x, 5.x, 6.x (type: SilX / creator: iSil) ← Most common
- PalmDOC (type: TEXt / creator: REAd)

## Notes
- This app reads the text/HTML content from .pdb iSilo documents
- Images within documents are not currently extracted
- Protected/encrypted documents will show garbled text
